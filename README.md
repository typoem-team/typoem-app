# Typoem 앱

> *Type + Poem* — 친구들과 함께 영어 시와 소설을 읽고 생각을 나누는 공간

[Typoem](https://github.com/typoem-team/typoem-web)의 Android 앱입니다. 웹에서 쓰던 계정과 방을 휴대폰에서 그대로 이용할 수 있습니다.

## 설치하기

Android 7.0 이상에서 사용할 수 있습니다.

- **[원스토어에서 받기](https://m.onestore.co.kr/v2/ko-kr/search?keyword=typoem)**
- **[APK 파일 직접 받기](https://github.com/typoem-team/typoem-app/releases/latest)**

> APK로 설치할 때 "출처를 알 수 없는 앱" 경고가 나오면, 안내에 따라 설치를 허용해 주세요.

---

## 앱에서만 쓸 수 있는 기능

화면과 기본 기능은 [웹](https://typoem-app.onrender.com)과 같고, 앱에서는 아래 기능을 더 쓸 수 있습니다.

| 기능 | 설명 |
| --- | --- |
| 홈 화면 위젯 | 오늘의 시와 연속 읽기 기록을 홈 화면에서 바로 봅니다. |
| 아침 알림 | 정해 둔 시각에 오늘의 시가 도착했다고 알려 줍니다. |
| 초대 코드 공유 | 초대 코드를 카카오톡 등 다른 앱으로 바로 보냅니다. |
| 휴대폰에 맞춘 사용감 | 테마에 맞춘 상태 표시줄, 뒤로 가기 버튼, 진동 피드백을 지원합니다. |
